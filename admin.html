🛠️ Panduan Menghubungkan Firebase

Agar 8 HP siswa dan laptop Guru dapat saling terhubung di Vercel, lakukan 2 langkah singkat berikut di Firebase Console (proyek kalor3-ff4af):

1. Aktifkan Realtime Database: Buka Firebase Console > Realtime Database ↗, klik Create Database, pilih lokasi (disarankan Singapore / asia-southeast1), lalu klik Next dan Enable.
2. Aktifkan Anonymous Authentication: Buka Firebase Console > Authentication > Sign-in method ↗, klik Anonymous (Anonim), aktifkan toggle Enable, lalu klik Save.
3. Salin Aturan Keamanan (Rules): Pada tab Rules di Realtime Database, tempelkan aturan dari file database.rules.json lalu klik Publish.
